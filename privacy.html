Site information

Privacy

This collection is designed to minimize data collection. The learning activities do not require a name, email address, student ID, account, or login.

What This Site Does Not Collect

The site does not send your activity answers, draft writing, grades, or completion information to the site creator or to your instructor. It does not use advertising trackers or analytics scripts.

Browser Storage in Some Labs

Some interactive labs use your browser's local storage so you can resume an activity. Most saved information is limited to progress, such as the question you reached or whether you completed the lab.

A small number of labs also save writing that you type into an optional practice or transfer area. That writing stays in your browser and is not submitted to this website. Because local browser storage can remain after you close the page, another person using the same browser profile on a shared computer could potentially see saved work if they reopen the same activity.

Using a shared computer? Use the activity's Clear My Saved Writing or Practice Again control when available, or clear the site's browser data when you finish. Avoid entering information you would not want left on a shared device.

Optional Reflection Pages

The optional reflection page displays prompts only. It does not provide a response box and does not collect, store, or submit a reflection response. If your instructor assigns a reflection, respond in Canvas or wherever your instructor directs you.

GitHub Pages Hosting

If this site is published through GitHub Pages, GitHub provides the web hosting. GitHub may process ordinary technical information needed to deliver and secure the site, including information associated with a web request such as an IP address. This hosting-layer processing is separate from the learning activities themselves.

Other Websites

If a page links to an outside website, that service has its own privacy practices. This site uses a no-referrer policy so the browser does not send this page's address as referrer information when you follow an external link.
