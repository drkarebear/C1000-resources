Code 2 · Analyze

ANALYZE ≠ Summarize

“Analyze how the author's use of repetition shapes the tone of the passage.”

Which response is actually analysis?

ANALYZE: break something into parts and explain how those parts work, connect, or create an effect.
Plain-language question: “What is happening here, and how/why does it matter?”
Code 3 · Evaluate

EVALUATE Means Judge Using Reasons

“Evaluate the effectiveness of the author's evidence.”

What does the assignment want?

EVALUATE: make a judgment using criteria or reasons.
Plain-language question: “How strong, effective, credible, useful, or successful is this—and why?”
Code 4 · Imply + Assumption

Sometimes the Meaning Is Not Stated Directly

“What does the advertisement imply about success, and what assumption about its audience does it rely on?”

Which interpretation best matches these words?

IMPLY: communicate something without stating it directly.
ASSUMPTION: an idea treated as true without being fully argued or proven.
Code 5 · Context + Significant

The Clue May Be Outside the Sentence

“Explain the historical context of the speech and identify one significant detail.”

What does context mean here?

CONTEXT: relevant circumstances surrounding an idea, event, text, quotation, or decision.
SIGNIFICANT: important in a way you can explain—not merely noticeable.
Code 6 · Qualify

QUALIFY Does Not Mean “Make It Better”

“Qualify the claim that social media is harmful to teenagers.”

Which move qualifies the claim?

QUALIFY: limit, complicate, or add conditions to a claim so it is more accurate.
Plain-language question: “When is this true? When might it not be? What limits belong on this claim?”
Code 7 · Synthesize

SYNTHESIZE Means Put Sources Into Conversation

“Synthesize the three sources to explain why students leave college before completing a degree.”

Which response is closest to synthesis?

SYNTHESIZE: combine ideas from multiple sources to show relationships, patterns, agreements, tensions, or a larger conclusion.
