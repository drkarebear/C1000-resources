Using a mini-lab in Canvas

The two sharing buttons are generated from the published location of this page, so once the site is live on GitHub Pages they copy the full public URL automatically.

1. Link itUse Copy student link anywhere Canvas accepts a hyperlink: Modules, Pages, Assignments, Announcements, or messages.
2. Embed itUse Copy Canvas embed, open the Canvas HTML editor, and paste the iframe code where you want the activity to appear.
3. If Canvas blocks itInstitutional Canvas settings can restrict external iframes. The direct student link will still be the simplest fallback.
